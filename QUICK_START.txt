# Railway Reservation System - Quick Start Guide

## 🚀 Quick Setup (5 Minutes)

### For Windows Users:

```powershell
# 1. Navigate to backend directory
cd backend

# 2. Create .env file (copy template)
copy .env.example .env

# 3. Edit .env with your Neon connection string
notepad .env

# 4. Install dependencies
pip install -r requirements.txt

# 5. Run the backend
python -m uvicorn main:app --reload
```

### For Mac/Linux Users:

```bash
# 1. Navigate to backend directory
cd backend

# 2. Create .env file (copy template)
cp .env.example .env

# 3. Edit .env with your Neon connection string
nano .env
# or
vi .env

# 4. Install dependencies
pip install -r requirements.txt

# 5. Run the backend
python -m uvicorn main:app --reload
```

## 🔧 .env File Setup

Create `.env` file in `backend/` directory with:

```
DATABASE_URL=postgresql://user:password@ep-xxxxx.neon.tech/dbname?sslmode=require
SECRET_KEY=your-random-secret-key-here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

**To generate SECRET_KEY in Python:**
```python
import secrets
print(secrets.token_urlsafe(32))
```

## 🌐 Connecting Frontend to Backend

Update your frontend API client to use:
```
http://localhost:8000
```

Example in Next.js:
```typescript
// frontend/src/lib/api.ts
const API_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:8000';

export async function fetchTrains() {
  const response = await fetch(`${API_URL}/api/trains`);
  return response.json();
}
```

## 🔍 Troubleshooting

| Issue | Solution |
|-------|----------|
| `ModuleNotFoundError: No module named 'dotenv'` | Run `pip install python-dotenv` |
| `psycopg2 error` | Run `pip install psycopg2-binary` |
| `Connection refused` | Check DATABASE_URL in .env |
| `relation does not exist` | Run SQL script from NEON_SETUP_GUIDE.txt |
| `CORS error` | CORS is enabled for all origins in main.py |
